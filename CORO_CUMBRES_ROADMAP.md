# CORO CUMBRES Roadmap

## V0.1 Current

- Library global de canciones
- Sets persistentes
- Tipos: Playlist, Misa, Misa Dominical
- Template litúrgico completo para Misa Dominical
- Drag Library -> momento litúrgico
- Varias canciones por momento
- Reordenamiento dentro del momento
- Duplicar Set/Misa sin duplicar canciones
- Compartir/exportar Set JSON
- Vista compartida móvil estructurada por momentos
- Presenter por canción
- Display azul karaoke con canción completa y auto-fit
- Modelo de acordes por línea con posición
- Toggle Presenter/Display para Letra / Letra + Acordes
